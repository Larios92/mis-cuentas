# Mi Bolsillo Alcanza

App web personal para llevar ingresos y gastos: quincenas, córdobas y
dólares (y otras monedas), tarjetas, deudas, cuentas y sincronización
entre dispositivos.

- Los datos se guardan en tu navegador y, si inicias sesión, se sincronizan.
- No uses esta app para guardar números de tarjeta ni contraseñas.
- Es una versión de prueba de uso personal. Todos los derechos reservados
  (ver LICENSE).

Tasas automáticas: [Rates By Exchange Rate API](https://www.exchangerate-api.com)
